## ✨ Overview

ComplianceOS is a next-generation compliance platform that helps organizations manage regulations, monitor risks, analyze documents, and generate smart reports from one unified dashboard.

Instead of using multiple disconnected tools, ComplianceOS brings everything together into one powerful system.

## ⚙️ Quick Start

### Clone Repo

```bash id="6g3k1w"
git clone https://github.com/aditya-30-05/Compliance-OS-.git
cd Compliance-OS-
```

### Install Requirements

```bash id="o58q2x"
pip install -r requirements.txt
```

### Add Environment Variables

```env id="n28h7e"
OPENAI_API_KEY=your_key
SECRET_KEY=your_secret
DATABASE_URL=sqlite:///compliance.db
```

### Run Server

```bash id="l0l4n1"
uvicorn backend.app:app --reload
```
